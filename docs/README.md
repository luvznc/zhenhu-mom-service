# 交付说明

## 交付内容

本目录是一套完整的移动端小程序原型与后续开发资料，面向“居家母婴护理AI智能匹配”项目。

| 文件 | 用途 |
| --- | --- |
| `../index.html` | 可运行高保真原型入口 |
| `../src/styles.css` | 视觉样式、移动端布局、页面组件样式 |
| `../src/app.js` | 页面切换、表单交互、AI匹配加载态、护士卡片交互 |
| `../data/mock-data.json` | 原型模拟数据 |
| `PRD.md` | 产品需求文档 |
| `DEVELOPMENT.md` | 技术实现与工程说明 |
| `API.md` | 后端接口草案 |
| `DATA_MODEL.md` | 数据模型草案 |
| `INTERACTION_SPEC.md` | 页面结构与交互说明 |
| `DESIGN_SYSTEM.md` | 高端视觉设计系统 |
| `AI_INTAKE_QUESTIONNAIRE.md` | 专业AI需求采集问卷与权重依据 |

## 评审顺序

1. 打开原型页面，先走完整业务流程。
2. 对照 `INTERACTION_SPEC.md` 确认页面结构与动效。
3. 对照 `PRD.md` 确认 MVP 范围。
4. 技术团队基于 `DEVELOPMENT.md`、`API.md`、`DATA_MODEL.md` 估算开发周期。
