# AI需求采集专业问卷设计

## 设计目标

将原型中的三项粗粒度问题升级为能够支撑“护士 + 家庭”非标场景匹配的专业采集体系。问卷用于服务匹配、风险预警、服务过程监管和后续质量回传，不用于医疗诊断。

## 问卷模块

| 序号 | 模块 | 匹配目的 |
| --- | --- | --- |
| 01 | 当前护理阶段 | 判断产前准备、产后早期、产褥期或产后康复的服务重点 |
| 02 | 分娩方式与产后恢复 | 匹配剖宫产、会阴伤口、出血/血压观察等经验 |
| 03 | 孕产妇健康风险 | 匹配血压、血糖、贫血、伤口异常、情绪支持等能力 |
| 04 | 新生儿基本情况 | 匹配早产儿、低体重儿、多胎、NICU出院后照护经验 |
| 05 | 新生儿观察重点 | 匹配黄疸、喂养不足、体温、呼吸、脐部护理能力 |
| 06 | 喂养方式与困难 | 匹配母乳指导、混合喂养记录、配方奶冲调消毒能力 |
| 07 | 睡眠与居家安全 | 匹配安全睡眠指导、环境风险识别能力 |
| 08 | 家庭环境与支持 | 匹配距离、通勤、家庭沟通与夜间支持能力 |
| 09 | 服务强度与时间 | 匹配白班、夜间、住家、短期指导等排班能力 |
| 10 | 护士偏好与合规确认 | 匹配本地化资源、专业方向、履历与平台闭环接受度 |

## AI匹配权重示例

| 触发条件 | 提升权重 |

| 剖宫产恢复 | 切口观察、产科经验、异常识别 |
| 高血压/出血重点观察 | 急救实操、指标记录、异常上报 |
| 早产儿/低体重儿 | 早产儿护理、低体重儿喂养、黄疸观察 |

## 权威依据

- WHO postnatal care guideline：产后应关注母体生理评估、新生儿危险信号、喂养、家庭支持和持续照护。
- ACOG postpartum care guidance：产后照护应评估身体、社会和心理健康，包括情绪、婴儿照护与喂养、睡眠疲劳、身体恢复和慢病管理。
- CDC urgent maternal warning signs：产后一年内需识别头痛、视觉改变、发热、胸痛、呼吸困难、严重腹痛、异常出血、腿/手臂红肿疼痛、自伤或伤害婴儿想法等警示信号。
- CDC/AAP safe sleep recommendations：婴儿睡眠应仰卧、使用坚实平坦睡眠表面、同房不同床、避免软寝具和过热。
- AAP jaundice guidance：新生儿黄疸需进行风险评估和出院后随访，喂养不足可能增加高胆红素风险。
