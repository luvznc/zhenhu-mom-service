# AI需求采集专业问卷设计

## 设计目标

将原型中的三项粗粒度问题升级为能够支撑“护士 + 家庭”非标场景匹配的专业采集体系。问卷用于服务匹配、风险预警、服务过程监管和后续质量回传，不用于医疗诊断。

## 匹配规则结构

### 1. 硬门槛

- 法定资质/材料状态满足具体服务项目要求。
- 平台认证处于有效且可接单状态；P0见习人员不得独立承接订单。
- 服务区域、班次、日期和预算有交集。
- 选择含餐服务时，护理师必须具备有效含餐专项认证。
- 选择IoT服务时，护理师必须完成设备记录、数据质量和异常升级培训。
- 高风险或不适宜居家服务的需求先进入人工评估，不直接推荐。

### 2. 动态评分

`总分 = 专业适配 + 月嫂专项 + 风险胜任 + 履约质量 + 本地与排班 + 价格适配 - 风险惩罚`

总分仅用于排序。前端必须同时展示硬门槛通过情况、前三项主要加分原因、潜在不匹配项和数据更新时间。

### 3. 质量回传

订单结束后回传护理日志完整率、餐饮服务完成率、IoT预警复核时效、投诉、复训、家庭评价和异常结论。回传可影响后续权重、专项证复审和课程推荐，但不得自动改变法定资质状态。

## 权威依据

- WHO postnatal care guideline：产后应关注母体生理评估、新生儿危险信号、喂养、家庭支持和持续照护。
- ACOG postpartum care guidance：产后照护应评估身体、社会和心理健康，包括情绪、婴儿照护与喂养、睡眠疲劳、身体恢复和慢病管理。
- CDC urgent maternal warning signs：产后一年内需识别头痛、视觉改变、发热、胸痛、呼吸困难、严重腹痛、异常出血、腿/手臂红肿疼痛、自伤或伤害婴儿想法等警示信号。
- CDC/AAP safe sleep recommendations：婴儿睡眠应仰卧、使用坚实平坦睡眠表面、同房不同床、避免软寝具和过热。
- AAP jaundice guidance：新生儿黄疸需进行风险评估和出院后随访，喂养不足可能增加高胆红素风险。
- 人力资源和社会保障部门家政服务员职业信息及国家职业技能标准：母婴护理相关工作包含孕产妇营养、产后恢复、新生儿喂养照护及家庭事务等能力。
- 国家卫生健康委医疗护理员培训要求：母婴护理相关培训涵盖基本法律、安全、营养、产妇与新生儿照护等内容。
- 医疗器械监督管理条例及分类规则：医疗用途设备需按分类实施注册/备案和监管，消费级数据不得被产品包装为诊断结论。
