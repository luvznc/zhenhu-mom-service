# 高端母婴护理设计系统

## 1. 视觉关键词

- 专业医疗信任感
- 温暖家庭护理氛围
- 高端 O2O 双端平台
- AI 可解释、流程可追溯
- iOS 质感、现代极简、卡片式信息结构

## 2. 色彩系统

| 色彩 | 变量 | 用途 |
| --- | --- | --- |
| 浅医疗蓝 | `#DDF1F5` | 背景、AI模块、信息提示 |
| 暖白 | `#FFF9F4` | 页面主底色、卡片底色 |
| 柔和桃色 | `#FAD8CF` | 母婴温度、重点提示、插画氛围 |
| 薄荷绿 | `#B8DFDC` | 信任、健康、闭环保障 |
| 深医疗蓝 | `#27445C` | 标题、主按钮、核心信息 |

## 3. 组件风格

| 组件 | 规范 |
| --- | --- |
| 手机容器 | iOS设备比例、Dynamic Island、柔和外发光 |
| 卡片 | 24-34px圆角、半透明暖白、轻玻璃拟态、低饱和阴影 |
| 主按钮 | 深医疗蓝渐变，圆角18px，高度52px |
| 标签 | 胶囊形，浅医疗蓝底，深薄荷绿文字 |
| 图标 | 医疗十字、AI圆环、盾牌、家庭、婴儿，线性几何化 |
| 数据卡 | 三列或双列网格，突出数字和短说明 |
| 认证阶梯 | P0-M4五段稳定网格，选中项深色，详情在下方更新 |
| 服务模式 | 双段选择器，不含餐/含餐切换后范围与价格同步变化 |
| IoT状态 | 稳定、关注、紧急分别使用薄荷绿、暖橙、桃红，文字状态不可缺失 |
| 课程卡 | 明确对象、课时、学习形式、价格和证书性质，避免营销化大标题 |

## 4. AI匹配界面规范

- 必须展示“匹配层、预测层、成长层”，不要只展示推荐结果。
- 护理师卡片必须包含本地化优势、法定材料状态、平台等级、餐饮/IoT专项、专业方向、经验、匹配分与动态权重标签。
- 推荐结果必须展示 AI 推荐解释，避免黑箱感。
- 合规提示需在匹配页显著出现：AI只预警、不诊断；医疗护理操作由具备相应法定资质且胜任该项目的人员负责。

## 5. 交互动效

| 场景 | 动效 |
| --- | --- |
| 页面切换 | 轻微横向滑入 + 透明度过渡 |
| 选中表单项 | 卡片变为浅医疗蓝渐变，并出现阴影 |
| 点击匹配 | 玻璃拟态遮罩 + 彩色旋转加载 |
| 护士卡片悬停 | 轻微上浮，阴影增强 |
| AI分数 | 圆形渐变轨道缓慢旋转 |

## 6. 双端平台表达

- 用户端：强调安心、低负担、可解释推荐。
- 护理师端：强调认证、接单效率、收入、能力成长与履约安全。
- 平台端：强调订单监管、异常工单、防跳单、质量回传。
