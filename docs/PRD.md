# 产品需求文档

## 1. 产品定位

“居家母婴护理AI智能匹配”是服务于孕产妇家庭与专业护士的 O2O 双端平台。平台通过 AI 贯穿“匹配、服务过程、质量回传、自优化”全流程，实现家庭需求与护士能力的精准连接。

## 2. 核心用户

| 角色 | 核心诉求 |
| --- | --- |
| 孕产妇家庭 | 找到专业、可信、价格可接受、服务过程可监管的居家护理人员 |
| 专业护士 | 获得稳定客源、安全履约、提升收入与职业发展 |
| 平台运营 | 管理护士资质、订单履约、异常工单、投诉仲裁与服务质量 |

## 3. MVP范围

### 用户端

- 微信登录与隐私授权
- AI需求采集：孕产妇状况、新生儿状况、家庭环境
- 智能匹配结果：匹配分、预测满意度、推荐解释
- 护士详情：资质、本地化优势、专业方向、经验年限、动态权重标签
- 签约支付：电子合同、资金托管、保险说明、防私下交易条款
- 服务监管：签到、护理日志、健康指标、异常反馈、评价

### 护士端

- 入驻认证
- 接单邀约
- 服务签到
- 护理日志上传
- 异常处理
- 收入结算

### 平台后台

- 护士资质审核
- 订单与服务监管
- 匹配规则配置
- 投诉与异常工单
- 风控与防跳单
- 数据回传与模型优化

## 4. AI匹配体系

| 层级 | 说明 |
| --- | --- |
| 匹配层 | 多维静态标签 + 动态权重，生成护士推荐排序 |
| 预测层 | 根据历史服务数据预测满意度、履约风险和异常风险 |
| 成长层 | 护理日志、评价、异常事件、回访记录持续回传，优化本地化知识图谱 |

## 5. 合规边界

- AI只做风险预警与匹配辅助，不进行医疗诊断。
- 最终护理操作由持证护士负责。
- 涉及诊断、治疗、用药等事项，必须建议用户到正规医疗机构。
- 平台负责资质审核、履约流程监管、合同与投诉处理。
