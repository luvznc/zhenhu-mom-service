# 产品需求文档

## 1. 产品定位

“居家母婴护理AI智能匹配”是服务于孕产妇家庭与医护背景母婴护理师的 O2O 双端平台。平台通过系统培训、标准化考核、透明认证与 AI/IoT 闭环监管，补齐护理人员在月子营养、产褥专项和家庭服务方面的能力短板，实现家庭需求与可验证能力的精准连接。

差异化定位：不是仅撮合供需的家政中介，而是“人才培养与认证 + 精准匹配 + 标准履约 + 持续质量改进”的母婴护理服务平台。

## 2. 核心用户

| 角色 | 核心诉求 |
| --- | --- |
| 孕产妇家庭 | 找到专业、可信、价格可接受、服务过程可监管的居家护理人员 |
| 医护背景护理师 | 补齐月嫂专项能力，获得稳定客源、安全履约、等级晋升与收入提升 |
| 社会母婴从业者 | 参加透明、可考核的付费培训，获得能力证明和就业机会 |
| 平台运营 | 管理法定资质、平台认证、培训、订单、IoT预警、投诉与服务质量 |

## 3. MVP范围

### 用户端

- 微信登录与隐私授权
- AI需求采集：孕产妇、新生儿、家庭环境、兰州地域偏好、餐饮/家务边界、IoT偏好
- 智能匹配结果：匹配分、预测满意度、推荐解释
- 护理师详情：法定资质、P0-M4平台等级、五维成绩、含餐/IoT专项、本地化优势与质量记录
- 签约支付：含餐/不含餐方案、IoT设备包、服务边界、电子合同、托管与保险
- 服务监管：签到、护理日志、餐饮记录、IoT趋势、人工复核、异常反馈与评价
- 认证中心：等级规则、五维考核、发证有效期、年审、降级和退出说明
- 成长学院：分层课程、实操考核、报名付费、带教与晋级路径
- 地域服务：兰州四区服务圈、本地人才供给、饮食/语言/环境偏好和通勤响应

### 护理师端

- 入驻认证
- 基线测评、选课、实操预约、考试、证书与晋级
- 接单邀约
- 服务签到
- 护理日志上传
- 异常处理
- 收入结算

### 平台后台

- 护士资质审核
- 平台能力认证、专项证、年审、复训、暂停与退出
- 课程、班级、师资、报名、订单、退款与培训收入
- 设备接入、数据质量、预警规则、人工复核与升级处置
- 订单与服务监管
- 匹配规则配置
- 投诉与异常工单
- 风控与防跳单
- 数据回传与模型优化

## 4. AI匹配体系

| 层级 | 说明 |
| --- | --- |
| 匹配层 | 多维静态标签 + 动态权重，生成护士推荐排序 |
| 预测层 | 根据历史服务数据预测满意度、履约风险和异常风险 |
| 成长层 | 护理日志、评价、异常事件、回访记录持续回传，优化本地化知识图谱 |

### 匹配执行顺序

1. 硬门槛：身份/法定材料有效、平台状态可接单、服务区域、排班、风险场景胜任、餐饮/IoT专项资格。
2. 动态评分：母婴照护、营养月子餐、家政规范、风险识别、沟通履约、距离与价格适配。
3. 预测排序：满意度、取消风险、迟到风险和异常风险，必须展示可解释原因。
4. 质量回传：护理日志、餐饮记录、IoT预警、人工复核、投诉与评价更新个人画像及复训建议。

### 地域匹配维度

- 服务圈：首期覆盖城关、七里河、安宁、西固，按实时供给配置可服务街区。
- 人员画像：常驻区域、本地学习/工作经历、通勤方式、夜间交通和跨区履约稳定性。
- 家庭适配：饮食习惯、普通话/方言偏好、长辈参与和居家环境记录需求。
- 合规边界：地域偏好只参与适配排序，不得降低法定资质、平台等级或专项能力硬门槛。

## 5. 平台认证体系

| 等级 | 定位 | 接单边界 |
| --- | --- | --- |
| P0 | 见习/培训中 | 不得独立接单，必须带教 |
| M1 | 基础母婴护理员 | 低风险基础生活照护与记录 |
| M2 | 专业母婴护理师 | 常规居家母婴服务，专项服务须另行认证 |
| M3 | 高级母婴护理师 | 复杂常规场景和高级专项，仍须遵守转诊边界 |
| M4 | 专家督导 | 联合评估、带教和质量复盘，不扩张医疗权限 |

考核维度：母婴专业照护30%、营养与月子餐20%、家政服务规范15%、风险识别与升级20%、沟通与履约15%。权重、分数线和订单门槛均为平台规则，可按试点数据校准。

## 6. 合规边界

- AI只做风险预警与匹配辅助，不进行医疗诊断。
- 平台能力等级必须标明“内部评价”，不得包装为国家职业资格或护士专业技术资格。
- 涉及医疗护理操作时，由具备相应法定资质且胜任该项目的人员负责；生活照护范围另行列明。
- 涉及诊断、治疗、用药等事项，必须建议用户到正规医疗机构。
- 消费级可穿戴设备不能替代医用设备或诊疗；医疗用途设备须核验注册/备案信息。
- 平台负责资质审核、培训认证、履约监管、合同、数据授权和投诉处理。
