# 交互说明

## Header

- 展示产品名称和当前页面任务。
- 用户在采集页选择选项后，进度条实时更新。
- 页面切换采用横向轻动效，模拟小程序页面进入感。

## Body

### AI需求采集

- 三张问题卡片：孕产妇状况、新生儿状况、家庭环境。
- 采用单选按钮，选中后显示绿色高亮。
- 每个选项附带简短说明，让用户知道为什么需要采集该信息。

### 智能匹配结果

- 展示“匹配层、预测层、成长层”三层体系。
- 展示合规提示：AI只预警不诊断。
- 护士卡片包含本地化优势、专业方向、经验年限、距离、匹配分、预计满意度和动态权重标签。
- 点击护士卡片展开更完整的AI推荐解释。
- 双击护士卡片进入护士详情页。

### 签约与服务监管

- 签约页突出电子合同、资金托管、保险与防私下交易条款。
- 服务监管页展示签到、护理日志、健康指标和异常反馈入口。

## Bottom Bar

- 采集页固定展示主按钮“开始AI智能匹配”。
- 点击后展示加载遮罩，说明后台正在计算专业能力、距离、排班稳定性、历史满意度和风险标签权重。
- 加载完成后自动进入匹配结果页。

## 视觉原则

- 医疗专业：低饱和蓝绿色、清晰边框、稳重信息层级。
- 家庭信任：温和暖色提示、柔和卡片阴影、清晰解释文案。
- 移动优先：组件宽度、按钮高度和文字行距均按小程序触控体验设计。
