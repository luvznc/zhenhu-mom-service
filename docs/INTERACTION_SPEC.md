# 交互说明

## Header

- 展示产品名称和当前页面任务。
- 用户在采集页选择选项后，进度条实时更新。
- 页面切换采用横向轻动效，模拟小程序页面进入感。
- 二级页面标头固定在状态栏下方，滚动时保留返回按钮、栏目名和页面标题。

## 导航与返回

- 每次进入新页面记录真实来源；同一页面连续点击不重复加入历史。
- 页面内返回按钮只返回上一个实际访问页面，不使用签约页、详情页等写死的默认目标。
- 返回时恢复上一页离开前的滚动位置；新进入的页面从顶部开始展示。
- 浏览器前进、后退与小程序页面内返回共用同一历史状态，分支跳转后不保留无效的重复路径。
- 通过链接直接打开某个二级页面时，该页面返回首页，不补造用户未访问的中间页面。

## Body

### AI需求采集

- 13个专业模块：阶段、分娩恢复、产妇风险、新生儿情况、观察重点、喂养、安全睡眠、家庭环境、地域偏好、服务强度、餐饮家务、IoT和护理师偏好。
- 同时支持单选与多选，选中后显示绿色高亮，进度按已完成模块计算。
- 每个选项附带简短说明，让用户知道为什么需要采集该信息。

### 智能匹配结果

- 展示“匹配层、预测层、成长层”三层体系。
- 展示合规提示：AI只预警不诊断。
- 护理师卡片包含本地化优势、法定资质、平台等级、含餐/IoT专项、专业方向、经验、距离、匹配分和动态权重标签。
- 点击护士卡片展开更完整的AI推荐解释。
- 双击护理师卡片进入专业档案页。

### 认证中心

- 点击P0-M4阶梯按钮，实时更新等级定位、接单边界和示例门槛。
- 五维考核与七步认证流程固定展示；“进入成长学院”承接培训转化。

### 签约与服务监管

- 含餐/不含餐使用分段控件切换，范围、排除项、服务费和托管总额实时更新。
- IoT设备包可单独开关，订单金额同步更新。
- 服务监管页展示签到、护理日志、餐饮完成、IoT快照和异常反馈入口。

### IoT智能监测

- 标签页切换产妇、新生儿与设备管理，面板高度稳定，避免切换时布局跳动。
- 黄色预警支持查看趋势或提交护理师复核，操作后给出轻提示。
- “同步最新数据”仅更新展示状态，不生成诊断结论。

### 培训学院

- 课程卡展示对象、课时、形式、演示价格和证书性质。
- 点击报名显示原型反馈；正式版本进入课程详情、协议、支付和退费规则确认。

### 兰州地域服务

- 城关、七里河、安宁、西固四个标签切换本地护理师供给、示例距离、响应和覆盖街区。
- 首页两类服务方案可直接进入签约页，并保持含餐/不含餐选择状态。
- 地域偏好进入AI解释、护理师档案和合同摘要，不作为降低专业门槛的理由。

## Bottom Bar

- 采集页固定展示主按钮“开始AI智能匹配”。
- 点击后展示加载遮罩，说明后台正在计算平台等级、母婴专项、餐饮/IoT能力、距离、排班和历史质量。
- 加载完成后自动进入匹配结果页。

## 视觉原则

- 医疗专业：低饱和蓝绿色、清晰边框、稳重信息层级。
- 家庭信任：温和暖色提示、柔和卡片阴影、清晰解释文案。
- 移动优先：组件宽度、按钮高度和文字行距均按小程序触控体验设计。
- 桌面原型展示：中间手机模型按浏览器可用高度自动等比缩放，100%浏览器比例下完整可见；左右说明栏独立滚动，不影响手机位置。
